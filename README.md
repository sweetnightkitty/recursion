# Odin Project Recursion

This project is a practice project that was built in accordance with the ODIN Project Recursion assignment to practice using recursion to solve problems:

* Problem 1: Calculate a specific amount of values in the Fibonnacci Sequence
* Problem 2: Merge Sort
